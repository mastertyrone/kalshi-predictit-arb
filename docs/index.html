kalshi-predictit-arb

Pay-per-call HTTP API that matches Kalshi markets to PredictIt contracts and returns both arbitrage directions priced after each venue's real fee drag, with worst-case net across settlement outcomes.

Base URL: https://x402.bankr.bot/0x69fb671637ed68881f66b9ebf305ec3ef5574f65/kalshi-predictit-arb
Operator: built and operated by Team Takatini · Status: live · No UI, no execution — data only.

What it computes (server-side)

  • Entity resolution: Kalshi markets matched to PredictIt contracts, gated on state, district, office, party, numeric strike, and cycle year. A party mismatch is a hard reject.
  • Both arb directions priced with real fee drag: Kalshi taker fee ceil(7 · P · (1−P))¢ per contract per leg; PredictIt 10% of winning-leg profit + 5% withdrawal drag.
  • Worst-case net across settlement outcomes. executable: true only at ≥ 1¢ net after all fee drag.
  • Depth: Kalshi order book walked to $100 / $500 / $1,000 notional. (PredictIt publishes no public depth; size within its $850/contract position limit.)
  • Annualized ROC to the later settlement date.
Gaps are indicative until checked against live depth, current fees, and resolution equivalence. This API makes no profit claims.

Request

GET /kalshi-predictit-arb?q=governor&limit=10&mode=opportunities
ParameterTypeDefaultDescription
qstring—Keyword filter (e.g. governor, senate).
limit1–2510Max pairs evaluated per call.
modeopportunities | allopportunitiesopportunities returns only executable pairs; all returns every evaluated pair.

Price & payment (x402)

  • $0.02 USDC per call, settled on Base via the x402 v2 exact scheme.
  • First request returns 402 with machine-readable payment requirements. Respond with a signed TransferWithAuthorization (EIP-3009) in the PAYMENT-SIGNATURE header (base64url-encoded JSON).
  • Your key never leaves your machine: sign offline, the facilitator submits (gasless for you). Refuse anything that isn't Base / exact / Base USDC / within your per-call cap.
  • Reference client: https://github.com/mastertyrone/kalshi-predictit-arb — offline EIP-712 signing, per-call cap, refusal checks. Key via X402_WALLET_KEY, never hardcoded.

Limits

  • Political markets only (Kalshi ↔ PredictIt overlap).
  • PredictIt depth is not public — size positions within its $850/contract limit.
  • Cold starts can take several seconds; allow a ~30s timeout.
